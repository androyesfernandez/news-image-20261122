Sum up 22 November's world news in one image: a broadsheet front page for
Sunday 22 November 2026 with 46 numbered stories from every region — the COP31
final deal text tabled in Antalya, the capture of cartel kingpin Chapo Isidro
in Sinaloa, Bahrain taking Iran to the UN — plus a UTC timeline, six big
numbers of the day, a dotted world map with numbered pins, and a red DATE
CHECK box listing the big stories deliberately excluded because they were
first reported on 19–21 November.

## Run it

```sh
python3 main.py
```

Writes `entry.png` (1024x1024, deterministic: two runs are byte-identical).
